## 1. Components Created

### `components/dashboard/campaigns/DeleteCampaignButton.tsx` (Client Component)
- Renders a "Delete" text button with a modal confirmation dialog.
- Uses `useTransition` for pending state during deletion.
- Calls `deleteCampaignAction(id)`, then `router.refresh()` on success.
- Shows inline error on failure. Dialog has Cancel + Confirm actions with backdrop blur.

### `components/dashboard/campaigns/CampaignForm.tsx` (Client Component, shared)
- Shared form for both Create and Edit flows, driven by `initialData?: Campaign` prop.
- Uses `useActionState` with `createCampaignAction` or `updateCampaignAction` depending on mode.
- `useFormStatus` drives the Submit button pending/disabled state with spinner.
- Displays inline `fieldErrors` from Zod under each field; top-level error banner for auth/server errors.
- Redirects to `/dashboard/campaigns` on success via `useEffect` watching `state.success`.
- Fields: Title (text), Description (textarea), Target Amount (number), Status (select), Deadline (datetime-local).

## 2. Pages Created

### `app/dashboard/campaigns/page.tsx` (RSC)
- Fetches all campaigns server-side via `getCampaigns()`.
- Renders a responsive table with columns: Title + Progress bar, Status badge, Target, Raised, Deadline, Actions.
- Color-coded status badges: draft (zinc), active (emerald), completed (blue), cancelled (red).
- Empty state with illustration and "Create Campaign" CTA.
- Error state banner if service returns an error.

### `app/dashboard/campaigns/loading.tsx`
- Animated pulse skeleton matching the table layout structure.

### `app/dashboard/campaigns/error.tsx` (Client Component)
- Error boundary with "Try Again" (calls `reset()`) and "Go to Dashboard" fallback links.

### `app/dashboard/campaigns/new/page.tsx` (RSC)
- Back navigation breadcrumb.
- Wraps `<CampaignForm />` in a styled card. No `initialData` → create mode.

### `app/dashboard/campaigns/[id]/edit/page.tsx` (RSC)
- Fetches campaign via `getCampaignById(params.id)`. Calls `notFound()` if missing.
- Dynamic `generateMetadata` using campaign title.
- Wraps `<CampaignForm initialData={campaign} />` → edit mode.
